
# Tech decisions
## Framework
    Using Nodejs and Expressjs we can achieve a powerfull, solid and flexible backend to handle files like Logs.
## DB
    At first, i decided go with MySQL, since it's my common DB. After that, i moved to MongoDB (even i'm not fully familiarized with it) since i though is the best way to handle logs from multiple microservices.
    - 
## Testing
    Going with Jest since it's powerfull and common tests framework for Node. Doing Unitary and E2E.
    Taking the names of microservices, we will generate a logs for actions with errors and ok responses.
## Docker as a project requeriment.

## Go with Javascript instead Typescrypt since i'm not going deeply in this case with this api, but Typescript will provide more readiblity in a bigger project.

## Integration with Codex
    To analyze a bunch of logs and find patterns and repetitive issues to generate insights.
    Our services will call an AI API (Codex) to check the logs (if logs are too long, will be in chunks), after that, our service process the response, create the analysis in the DB and retrieve the result, our service will handle the errors.

## DB
- Every log will have this schema:
    - `microservice` - from which microservice
    - `date`
    - `level` - Level error from microservice
    - `payload` - File resource
    - `message`
    - `id`
    
- Every analysis will have this schema:
    - `microservice` - from which microservice
    - `date`
    - `result` - Text or log generated by AI after process the logs.
    - `message` - A summary with the result.
    - `id`
    - `status` - [Pending, In progress, Completed]

# Api endpoints

## GET
- [GET] `/api/logs` - Retrieve list of logs, with filters [date, microservice, level, message], pagination.
- [GET] `/api/analysis/` - Retrieve List of analysis, with filters [date, microservice, message, status], pagination.
- [GET] `/api/analysis/:id` - Retrieve the analysis by {id}
- [GET] `/api/health` - Health check

## POST
- [POST] `/api/logs` - Receive a log to insert
- [POST] `/api/logs/analyze` - Receive a group of logs to analyze.
- [POST] `/api/logs/stored/analyze` - Receive a group of IDs of stored logs to analyze.
