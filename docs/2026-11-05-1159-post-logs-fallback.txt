Task: Implement approved POST /api/logs validation and fallback preservation.

Added strict body validation for the four documented microservices, supported
levels, real timezone-qualified ISO timestamps, required message, optional file
reference payload, types/lengths, and unknown fields. Parser accepts only UTF-8
application/json with 64 KiB limit and handles malformed/unsupported input safely.
Primary confirmed insertion returns 201. Invalid readable JSON or primary write
failure is stored as original JSON text in rejected_logs with request ID, timestamp,
reason/issues, and optional attempted primary ID. Confirmed fallback returns 202.
Neither write confirmed returns retryable 503. Writes use bounded timeouts.
No input payload or raw storage errors are printed to operational logs.

Documented same-database outage limitation, uncertain timeout outcomes, possible
duplicates on retry, and transport failures not being quarantined. Added v2.0
TODOs for fallback list/detail/correction/replay endpoints; no such routes added.
